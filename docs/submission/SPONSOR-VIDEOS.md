## What is real

Every terminal line, code card, page and explorer screen is captured output, not a mock-up.

- Terminal output: `video/proofs/sponsors/*.txt` (`mm cargo …`, `envio-cloud`, the API health check, the Render env vars with the Alchemy key masked as `••••`, the Render start-up log).
- Code cards: verbatim excerpts cut by `video/scripts-snippets.py` from `indexer/` and `backend/`.
- Pages and explorers: `video/public/live/*.png`, captured by `video/scripts-capture-sponsors.mjs stills`.
- The Envio end-to-end shot is a screen recording of the live `/notes` page, made by `video/scripts-capture-sponsors.mjs e2e` while it sent one bid (timings in `video/proofs/sponsors/envio-e2e.json`).

## Rebuild

```bash
cd video
voiceover/.venv/bin/python voiceover/place-sponsors.py   # after gen.py, if the cues change
npx remotion render SponsorMetaMask out/CargoFlow-MetaMask-AgentWallet-Plugin.mp4 --codec=h264 --crf=18
npx remotion render SponsorEnvio    out/CargoFlow-Envio-HyperIndex.mp4 --codec=h264 --crf=18
npx remotion render SponsorAlchemy  out/CargoFlow-Alchemy.mp4 --codec=h264 --crf=18
npx remotion render PromoAd         out/CargoFlow-Promo-30s.mp4 --codec=h264 --crf=18
```
